# Plan d'Action — 3 Lacunes Dirigeant

> Diagnostic issu de la Session 33 (25 Avril 2026) — 32 sessions de collaboration analysées

---

## Lacune #1 — Exécution Commerciale

**Constat** : 500 leads identifiés, 0 contacté en 17 jours. Le pipeline CRM existe mais aucune action commerciale n'a été exécutée.

### Plan d'action

| Priorité | Action | Échéance | KPI |
|----------|--------|----------|-----|
| 🔴 P0 | **Contacter 5 leads cette semaine** — choisir dans les segments PV et CHARPENTE (Personas 1 et 3) | 05/05/2026 | 5 messages envoyés |
| 🔴 P0 | **Activer les séquences LinkedIn** — publier les 4 séquences prêtes dans `sequences_linkedin.md` | 05/05/2026 | 4 séquences actives |
| 🟠 P1 | **Enrichir les leads prioritaires** — emails vérifiés via Apollo/Hunter pour les 30 leads du template Odoo | 09/05/2026 | 30 emails vérifiés |
| 🟠 P1 | **Pipeline n8n recrutement** — activer le scraping offres d'emploi → entreprises en tension | 12/05/2026 | Pipeline opérationnel |
| 🟡 P2 | **Objectif 50 contacts/mois** — cadence de prospection régulière | Mensuel | 50/mois |

### Règle opérationnelle
> **Lundi et Jeudi = jours de prospection.** Bloquer 1h minimum sur ces 2 jours pour les actions commerciales. Non négociable.

## Lacune #2 — Focus vs Dispersion

**Constat** : Trop de chantiers ouverts simultanément (GED, PKM, RAG, Obsidian, veille, templates, Odoo, challenge, site web, n8n...). Chaque session ouvre de nouveaux fronts sans finir les précédents.

### Plan d'action

| Priorité | Action | Échéance |
|----------|--------|----------|
| 🔴 P0 | **Règle des 3 maximum** — ne pas avoir plus de 3 chantiers actifs en parallèle | Immédiat |
| 🔴 P0 | **Définir les 3 chantiers actuels** : 1) Prospection commerciale, 2) RAG/ChromaDB opérationnel, 3) Projets clients | Immédiat |
| 🟠 P1 | **Tout le reste en backlog** — GED, veille, templates, Odoo relances, site web = chantiers en attente | Immédiat |
| 🟡 P2 | **Revue hebdomadaire dimanche soir** — 15 min pour décider des 3 priorités de la semaine | Hebdo |

### Règle opérationnelle
> **Avant d'ouvrir un nouveau chantier, en fermer un.** Si un chantier technique est terminé → le remplacer par le suivant dans le backlog. Pas d'ajout sans retrait.

### Backlog ordonné (à attaquer quand un slot se libère)
1. Site web siriusingenierie.fr
2. SIRIUS Challenge V2
3. Fiches techniques V2 (après RAG complet)
4. Pipeline n8n
5. Cours Anthropic Academy
6. Veille CTICM/SCI complémentaire
7. Grasshopper paramétrique

## Lacune #3 — Posture Dirigeant vs Technicien

**Constat** : Le dirigeant passe trop de temps sur les outils IA et la tech (configuration RAG, ChromaDB, scripts Python) au lieu de se concentrer sur la vente, les clients et la stratégie. C'est un piège classique de l'ingénieur-dirigeant.

### Plan d'action

| Priorité | Action | Échéance |
|----------|--------|----------|
| 🔴 P0 | **Répartition temps** : 60% Clients/Production, 20% Commercial, 20% Tech/IA | Immédiat |
| 🔴 P0 | **Déléguer la tech à l'agent** — les configs RAG, scripts, corrections = travail de l'agent IA, pas du dirigeant | Immédiat |
| 🟠 P1 | **Rituel CA quotidien** — chaque matin, vérifier les factures en retard + relancer si nécessaire | Quotidien |
| 🟠 P1 | **Networking physique** — 1 événement/mois (CTICM, cluster BTP, CCI, salon) | Mensuel |
| 🟡 P2 | **Coaching professionnel** — explorer un accompagnement dirigeant (Julie ?) | Mai 2026 |

### Règle opérationnelle
> **"Est-ce que ce que je fais là génère du CA ?"** — se poser la question toutes les 2h. Si la réponse est non depuis plus de 4h, basculer sur une action commerciale.
