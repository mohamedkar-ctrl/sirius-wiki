# ☀️ MOC — Structures Photovoltaïques

> Carte de contenu pour les structures PV : ombrières, toitures, trackers.
> **Notebook NotebookLM associé** : NB3 — SIRIUS PV & Projets (73 sources)

---

## Types de structures
- **Ombrières de parking** — portées 10-16m, hauteur libre 2.20m min
- **Toitures industrielles** — surimposition PV sur charpente existante
- **Trackers** — structures monoaxiales, effort vent dynamique
- **Centrales au sol** — pieux battus, batardeaux

## Charges spécifiques PV
- Vent : EN 1991-1-4 + annexe modules PV (effet tunnel, succion)
- Neige : EN 1991-1-3 (accumulation entre rangées)
- Poids modules : ~12-15 kg/m² (cristallin) / ~8 kg/m² (couche mince)
