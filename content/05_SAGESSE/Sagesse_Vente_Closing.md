## Le tunnel de vente SIRIUS

```
PROSPECTION (Outbound / Inbound)
    │ Cold email, LinkedIn, recommandation, pipeline n8n
    ▼
SETTING (Qualification)
    │ Premier contact, qualification BANT, booking RDV
    ▼
DÉCOUVERTE (RDV 15 min)
    │ Comprendre le besoin, qualifier le budget/timing
    ▼
PROPOSITION (Estimation / Devis)
    │ Pré-étude gratuite, devis chiffré, références
    ▼
CLOSING (Négociation finale)
    │ Traitement objections, négociation prix, signature
    ▼
ONBOARDING (Lancement projet)
    │ Kick-off, collecte données, planning
```

## Étape 1 : SETTING — Qualification du prospect

### Framework de qualification BANT (adapté BE ingénierie)

| Critère | Question type SIRIUS | Signal positif |
|---------|---------------------|----------------|
| **B**udget | "Vous avez déjà une enveloppe pour l'ingénierie structure ?" | Oui, ou "ça dépend du devis" |
| **A**uthority | "C'est vous qui validez le choix du BE ?" | Oui, ou "avec mon DG" |
| **N**eed | "Vous avez un projet en cours qui nécessite un calcul structure ?" | Oui, avec deadline |
| **T**imeline | "C'est pour quand ? Quelle est la deadline bureau de contrôle ?" | < 3 mois |

### Signaux d'achat forts
- Recrute un ingénieur structure (= surcharge BE)
- Deadline projet proche (< 2 mois)
- Demande d'estimation / de devis
- Pose des questions techniques précises
- Mentionne un problème avec son BE actuel

### Signaux de non-achat
- "Envoyez-moi une plaquette" (sans question)
- "On verra plus tard" (pas de timeline)
- "Je transmets" (pas le décideur)
- Aucun projet identifié

## Étape 2 : DÉCOUVERTE — RDV 15 min

### Script de découverte SIRIUS

**Ouverture (2 min)**
```
"Merci d'avoir accepté cet échange. En 15 min, j'aimerais
comprendre comment vous gérez l'ingénierie structure sur vos
projets pour voir si Sirius peut vous être utile. Ça vous va ?"
```

**Questions de contexte (5 min)**
```
1. "Combien de projets [PV/CM] vous traitez par an ?"
2. "Comment vous gérez la partie calcul structure aujourd'hui ?
    BE interne ? Sous-traitant ?"
3. "Quels logiciels vous utilisez ? Tekla ? Robot ?"
4. "Quel est votre principal défi sur l'ingénierie structure ?"
```

**Questions de douleur (5 min)**
```
5. "Quand votre BE est en surcharge, comment vous gérez ?"
6. "Ça vous est déjà arrivé d'avoir un retard sur la note de
    calcul qui bloque le bureau de contrôle ?"
7. "Si vous pouviez changer UNE chose dans votre process
    d'étude structure, ce serait quoi ?"
```

**Proposition + CTA (3 min)**
```
"OK, je comprends bien la situation. Voici comment Sirius
pourrait vous aider : [1 phrase de valeur adaptée].

Pour avancer concrètement, je vous propose de faire une
estimation gratuite sur votre prochain projet — je vous
envoie un email avec les docs dont j'aurais besoin.
On se recale dans 1 semaine pour en discuter ?"
```

## Étape 3 : PROPOSITION — Devis

### Structure du devis SIRIUS

| Section | Contenu |
|---------|---------|
| **Contexte** | Rappel du projet, localisation, contraintes |
| **Périmètre** | Ce qui est inclus (NdC, modèle Tekla, plans, suivi BdC) |
| **Livrables** | Liste exacte des documents à livrer |
| **Planning** | Délai de livraison (semaines) |
| **Prix** | Forfait HT (pas de TJM affiché) |
| **Conditions** | Acompte 30%, solde à livraison |
| **Références** | 2-3 projets similaires anonymisés |

### Pricing — Règles
- Toujours en **forfait**, pas en TJM
- Inclure une marge de sécurité de 15-20% sur l'estimation interne
- Ne jamais donner de prix par téléphone au 1er appel
- Prix envoyé par email après le RDV, avec 48h de délai

## Étape 4 : CLOSING — Traitement des objections

### Top 5 objections BE ingénierie

| Objection | Réponse type |
|-----------|-------------|
| **"C'est trop cher"** | "Je comprends. Si on compare au coût d'un recrutement en CDI (50-60k€/an charges), le forfait ponctuel est un investissement bien plus flexible. Et sur ce projet, notre optimisation peut vous faire économiser [X k€] de tonnage acier." |
| **"On a déjà un BE"** | "Très bien — et comment ça se passe quand il est en surcharge ? Sirius peut servir de backup fiable, sans engagement long terme. On travaille comme ça avec [référence]." |
| **"Il faut que j'en parle à mon DG"** | "Bien sûr. Est-ce que je peux préparer un résumé d'1 page que vous pourriez lui transmettre ? Et on se recale à 3 la semaine prochaine ?" |
| **"Envoyez-moi un devis et on verra"** | "Avec plaisir. Pour que le devis soit pertinent, j'aurais besoin de [plans/cahier des charges]. Vous pouvez me les envoyer cette semaine ?" |
| **"Pas de projet en ce moment"** | "Pas de souci. Si je vous recontacte dans 2 mois, ça vous convient ? Et en attendant, je vous envoie notre fiche technique sur [sujet pertinent]." |

### Technique de closing : l'alternative
```
❌ "Alors, on signe ?"
✅ "On démarre semaine 20 ou semaine 21 ? Je m'adapte à votre planning."
```

## Étape 5 : NÉGOCIATION (inspiré E.Beltran)

### Principes de négociation B2B
1. **Ne jamais baisser le prix sans contrepartie** — Si remise, retirer un livrable
2. **Ancrer haut** — Le premier prix donné fixe le cadre mental
3. **Comprendre les vrais enjeux** — Le prix n'est jamais le vrai problème
4. **Avoir un BATNA** — Si le prospect ne signe pas, SIRIUS a d'autres leads
5. **Créer de l'urgence légitime** — "Mon planning se remplit vite sur Q2"

### Phrases de négociation
```
"Je peux ajuster le prix si on retire le suivi bureau de contrôle
du périmètre — est-ce que ça pourrait fonctionner ?"

"Pour ce budget, je peux vous faire une NdC simplifiée. Pour le
package complet (NdC + Tekla + suivi BdC), c'est le prix indiqué."

"Je comprends. Sachez que sur les projets suivants, les études
vont plus vite parce qu'on connaît vos standards — le prix
unitaire baissera naturellement."
```
