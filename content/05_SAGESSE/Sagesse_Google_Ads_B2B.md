## Pertinence Google Ads pour SIRIUS

> Google Ads est pertinent quand **le prospect cherche activement** une solution.
> Un développeur PV qui tape "bureau études structure photovoltaïque" est un lead chaud.

### Mots-clés pertinents SIRIUS

| Mot-clé | Volume estimé | Intention | CPC estimé |
|---------|--------------|-----------|------------|
| bureau études structure métallique | Moyen | 🟢 Forte | 3-5€ |
| calcul structure acier | Moyen | 🟢 Forte | 2-4€ |
| bureau études charpente métallique | Moyen | 🟢 Forte | 3-5€ |
| ingénieur structure photovoltaïque | Faible | 🔴 Très forte | 4-8€ |
| note de calcul eurocode | Moyen | 🟡 Moyenne | 2-3€ |
| sous-traitance bureau études structure | Faible | 🔴 Très forte | 5-10€ |
| dimensionnement ombrière PV | Faible | 🔴 Très forte | 5-8€ |
| étude structure panneaux solaires | Faible | 🟢 Forte | 3-6€ |

### Mots-clés négatifs (à exclure)
```

-gratuit -logiciel -télécharger -cours -exemple
```

## Annonces — Templates

### Annonce responsive (RSA)

**Titres (15 caractères max chacun) :**
```
T1: Bureau Études Structure
T2: Spécialiste Acier & PV
T3: -15% Tonnage Garanti
T4: Devis Gratuit 48h
T5: Expert Eurocodes
T6: NdC + Plans Tekla
T7: Sirius Ingénierie
T8: Réactif & Compétitif
```

**Descriptions (90 caractères max) :**
```
D1: Bureau d'études structure acier. Calcul Eurocodes + Tekla. Devis gratuit.
D2: Optimisation tonnage acier PV : -8 à 15%. Note de calcul validée BdC.
D3: Sous-traitance BE structure. Livraison en 2-3 semaines. Décennale en règle.
```

### Page de destination
- Créer une landing page dédiée (`sirius-ingenierie.fr/devis-structure`)
- Formulaire simple : Nom, Email, Téléphone, Type de projet, Message
- Pas de menu de navigation (pour maximiser la conversion)
- Inclure témoignages/références et chiffres clés

## Budget recommandé

| Phase | Budget/mois | Objectif |
|-------|-------------|----------|
| **Test** (M1-M2) | 150-300€ | Valider les mots-clés, CPC, taux conversion |
| **Optimisation** (M3-M4) | 300-500€ | Affiner les audiences, augmenter le volume |
| **Scale** (M5+) | 500-1.000€ | Si ROAS > 3x |

### Calcul ROI cible
```
Budget : 300€/mois
CPC moyen : 5€
Clics : 60/mois
Taux conversion LP : 5%
Leads/mois : 3
Taux closing : 30%
Clients/mois : ~1
Panier moyen : 5.000€
ROAS : 5.000/300 = 16.7x ✅
```

## KPIs Google Ads

| Métrique | Seuil acceptable | Seuil bon | Action si mauvais |
|----------|-----------------|-----------|-------------------|
| CTR | > 3% | > 6% | Retravailler les annonces |
| CPC | < 8€ | < 5€ | Affiner les mots-clés négatifs |
| Taux de conversion LP | > 3% | > 8% | Optimiser la landing page |
| Coût par lead | < 100€ | < 50€ | OK pour le B2B |
| Quality Score | > 5 | > 7 | Améliorer la pertinence |
